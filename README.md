# Logical Truth Table Calculator

## Description 
This system is built using HTML, CSS, and JavaScript.
This website is used to generate the logic truth tables automatically.

## How to use
1. Visit the website link at ([Kalkulator Tabel Kebenaran](https://tabel-kebenaran-gyshela.vercel.app/)).
2. Input a formula by clicking on it. For example, A∧B
3. Click the "Generate" button to generate the truth table.
4. Click the "CNF" button to generate the Conjunctive Normal Form. 
5. Click the "DNF" button to generate the Disjunctive Normal Form. 
6. Click the "Reset" button to clear the formula.
